# Rejeições e mensagens do InvoiCy (inv03xx)

> Fonte: [Códigos de retorno NFS-e do portal dos desenvolvedores](https://desenvolvedores.migrate.info/Integracoes/CodigosdeRetorno/NFSeRetornosinv/inv0301/). Clique no código para abrir o artigo original.

Mensagens geradas pelo **próprio InvoiCy**, não pela prefeitura. Valem para **todos os provedores**. Várias são só registros de histórico (ex.: inv0330, inv0335) e não exigem ação.

Quando a mensagem for **inv0328 - Mensagem retornada pela prefeitura**, o motivo real está no texto da prefeitura: procure-o na pasta do provedor em [03-rejeicoes](README.md). Lembre que o nome do campo no layout da prefeitura é diferente do layout InvoiCy; use o [layout De/Para](../01-layouts/layouts-provedores.md) para achar o campo correspondente.
